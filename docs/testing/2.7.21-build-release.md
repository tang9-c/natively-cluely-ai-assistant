## 验收边界

SEC-01 明文凭据为用户接受的非阻断风险，本轮不实施加密迁移。真实 QCLOUD 账号/模型响应、新设备 TCC、有声系统音频与完整会议、物理热插拔及新发行包人工亮暗主题验收均未执行。远程固定 WAV smoke 与隔离 UI 不替代这些项目。

macOS 的 ad-hoc 完整性检查不等于 Developer ID 签名或 Apple 公证；Windows 未配置 Authenticode。本轮不自动覆盖 `/Applications/CueUp.app`，用户正在检查的本地预览不受影响。

原始日志和 API/报告证据保存在本机私有目录，不提交安装包、原始日志或真实凭据。
