## 1. 启动与退出（优先执行）

- [ ] 完全退出后启动；启动画面／窗口尚未出现时就尝试正常退出，重复5次。macOS 用菜单或 Cmd+Q，Windows 用托盘／应用退出入口；无法在此阶段操作则记“未覆盖”，不要用强制结束代替。
- [ ] 正常打开后立即退出，重复5次；另在一场测试会议停止后退出一次。
- [ ] 每次都观察 Dock／任务栏及活动监视器／任务管理器：无崩溃弹窗、无卡死、进程自然结束；记录最长退出耗时。超过15秒仍未退出先记失败并留证，再做清理。
- [ ] 退出后重新打开，之前已保存的测试会议仍可查看；不要把单纯关闭窗口算作应用退出。

**通过标准：**上述可操作场景全部自然退出，无 SIGSEGV、挂起或记录丢失。15秒是本清单的故障观察线，不是产品性能承诺。

## 2. 线下多人身份标注

- [ ] 未注册／暂停本人声纹，用本地模型开始线下会议，三人轮流各说3段完整句子，包含“我来提供资料”。核对不因共用麦克风把所有发言标成“我”；没有身份证据时应为“身份未确认”。
- [ ] 注册本人声纹后，三人轮流发言，加入远场、短句和一次插话。有依据时可标“我 · 声纹匹配”；证据不足应保留未知，不把负匹配直接当作已确认他人，不凭一次匹配把多人片段整体认成本人。
- [ ] 会中将一段改为“其他参会者”，再将另一段明确改为“身份未确认”；会后重开确认保留。选两段批量纠正，再改其中一段文字，确认身份仍保留、其他片段未被连带修改。
- [ ] 未知身份说“我下周提供资料”时，检查生成的行动项：不能仅凭麦克风来源归给当前用户；原话“张三负责”允许提取张三。
- [ ] SenseVoice、Whisper 分别执行上述项目；记录他人误标本人、本人正确识别、未知及多人片段的数量。若本次没有生成摘要，任务归属项目记未测。

**通过标准：**没有按音源强行认本人；人工纠正保存可靠；摘要不无依据归责。不要求自动把其他人分成 A／B／C 或识别真实姓名。短测不能替代下文的声纹准确率验收。

## 3. 音频自愈

先正常说话并确认有转录，再一次只制造一种异常，记录故障、提示、恢复和新转录出现的时间。

- [ ] 会中拔掉当前 USB 麦克风／耳机；如回退到内置设备，设置应显示实际设备。继续说一句“拔插恢复测试”，确认新文字出现、旧文字保留。
- [ ] 播放获准的测试音频，切换默认输出设备；系统音频恢复后继续转录。检查正常的麦克风通道未被故障通道连带停止。
- [ ] 会中休眠再唤醒，继续说“唤醒恢复测试”；检查恢复状态与真实输入一致。
- [ ] 正常安静1分钟后再说话：不因安静反复报错或重启采集；恢复状态不能仅靠界面变绿判断。
- [ ] 在测试系统用户中撤销再恢复录音权限。无法自动恢复时应有明确操作提示；按提示操作后复测。不应静默重置权限或重启应用。平台不支持会中撤销时记录限制。

**通过标准：**可恢复的故障恢复后确实收到新音频／新转录；不能恢复时明确提示，不能假报成功或无限弹窗。中断期间未采集内容不要求补回。保存各次检测及恢复耗时，未设统一秒数门槛。

## 4. 编辑与保存

- [ ] 在同一测试会议修改摘要、行动项文字／负责人／期限，再删除一条行动项；只看到一份行动项清单，没有独立的“下一步”清单。
- [ ] 用中文输入法连续改字，修改一段已完成转录，再切页、重开会议、退出重启。确认最后一次修改和删除都保留，时间与人工身份纠正未丢失，文字不回跳。
- [ ] 修改转录后，原摘要不被静默覆盖；有摘要时应提示可能需调整。手工修正摘要后，后到的自动结果也不能覆盖它。
- [ ] 选具体错词并主动“记住”词对；在运行中的 SenseVoice 后续最终结果中复核新规则，再停用复核。记录具体输入／输出；若模型未产生对应错词，记“未触发”，不要算通过。普通整句修改不能自动增加词表，Whisper 不要求自动套用该词表。
- [ ] 如已配置历史检索，待索引更新后搜索修正专名，检查引用不持续显示旧错词；未配置则单列未测。

**通过标准：**以重新打开后的实际内容为准，不能只看“已保存”提示。真实保存失败／索引失败不能通过断网来模拟本地数据库故障；没有安全可用的故障注入条件就记录未测，不改真实数据库权限制造失败。

## 5. 分享纪要

- [ ] 编辑摘要及一条任务后，立即点“分享纪要 → 复制纪要”，粘贴到飞书测试输入框，**不发送**。应是最新修改，没有旧内容或重复行动项，中文、专名、列表可读。
- [ ] “分享纪要”只有复制纪要、导出 Word 两项。检查粘贴内容含标题、日期、摘要、决策及行动项，负责人／期限与已保存值一致；不包含私人验收标记、私人问答／分析、完整转录或跟进草稿。
- [ ] 导出 Word，用已登记版本的 Word／兼容阅读器打开，与复制内容逐项比较；内容一致、长段落完整、列表正常，无多余 Markdown 标记或空章节。
- [ ] 再次导出时取消保存对话框：不报错、不提示导出成功。修改一个词后立即导出，再确认文件包含新词。

**通过标准：**复制和 Word 使用同一份最新成功保存的内容；保存失败不能输出旧版本冒充成功；只复制／导出，不自动选群或发送。

完成以上快速清单仍不等于完成发布验收。沿用[原开发方案第6节](../engineering/2026-10-16-v2.8-trusted-meeting-development.md)，不得缩减为一次短测：

- 三平台、两种本地模型覆盖；线下／线上／混合各至少2场、每场至少20分钟，线下／混合至少3人。
- 冻结至少100段清晰本人、100段清晰非本人及独立噪声／重叠样本；他人误标本人率≤1%，清晰本人正确识别率≥80%，未知计入分母并单独报告。指标是工程准入目标，不是当前模型能力结论；资源未齐时保持待验。
- 每个平台的拔插、路由切换、休眠、权限和正常静音各至少3次；记录后端和耗时。
- 安全条件下的保存／索引失败重试、初次生成与编辑并发，以及真实用户库升级、备份恢复和凭据保护仍需独立证据。本清单不授权删除数据或调用付费服务。

验收执行完也只填写结论，**不正式发布**；发布另行确认。本次构建及本地检查证据见[合并验收记录](v2.8-merge-acceptance.md)。
